# Windows 原生支持

基线 `4c7426a4ce5b733bb32b32fc6fa2fe8438e05e9d`，工作分支 `feat/windows-support`。用户要求在既有 Ergora 之上实现 Windows 版本。

## 范围与归属

原生控制面复用已有应用函数；不复制模板或执行合同。跨平台锁放在现有状态所有者；进程管理继续由 processes 拥有。Windows Job Object 由进程调用和资料观察共同使用，用于控制后代生命周期，不作为每 Agent 的安全隔离。Linux 独有正式执行器 / mini / Forge 保持原实现，通过 WSL2 使用并给出显式平台提示。

## S10.1 原生运行适配

实现：`state.file_lock` 复用在记忆同步、资料观察与 kernel 操作；Windows 使用 msvcrt 字节锁，Linux 保留 flock。Windows 状态默认独立存储在 LocalAppData；显式 home / 环境变量优先。

`processes` 与 `research` 共同使用标准库 ctypes 实现的 Job Object。控制器先将可信 gate 子进程归入 Job，再允许启动用户命令或网络抓取；超时、取消、正常结束与控制器意外关闭由 Job 管理本地后代。抓取的归入前等待同样受墙钟预算约束。Job 不作为安全沙箱；外部 API / 远程计算取消仍由外部服务负责。

自有文本 IO 明确 UTF-8，CLI 外部文本 / JSON 和 Skill frontmatter 接受 BOM。Windows 命令优先原生 exe，拒绝隐式 batch 入口；自定义脚本可通过显式解释器启动。mini / Forge / 完整参考执行器在不支持的平台明确给出 Linux / WSL2 指引。冻结参考未修改；`.gitattributes` 使其保持原始字节，跨平台 checkout 不重写换行。

涉及源文件：`__main__`、`agents`、`cli`、`evaluation`、`kernel`、`memory`、`optimization`、`processes`、`projects`、`reference`、`reference_executor`、`research`、`skills`、`stage_driver`、`state`、`windows_job` 及两个 SDK driver。新增 `tests/test_processes.py` / `test_windows.py`，对既有 POSIX fixture 作窄范围平台跳过。

## S10.2 安装与交付

实现：`scripts/install.ps1` 提供 PowerShell 5.1 用户目录安装、可选 winget 基础依赖、GEPA / Temporal SDK、用户 PATH 与重复升级；使用原生 exe launcher，归属记录与 SHA 保护外来入口。Windows runner 用含中文和空格的安装路径真实安装两次，并检查外来入口保护。

README、[Windows 手册](../WINDOWS.md)、使用 / 训练 / Agent 手册和页面工具提示同步支持矩阵。原生控制面和 WSL2 内完整 Linux 工作流共享协议，但不共享正在写入的 SQLite / 虚拟环境 / 绝对路径。旧 HTML 仍为冻结 Linux 发行。

新增 `.github/workflows/portability.yml`：Ubuntu Python 3.11 / Windows Python 3.12，构建并安装 wheel、冻结内容身份、应用 / 合同回归及 Windows PowerShell 5.1 安装器。此处在真实运行前不标为通过。
