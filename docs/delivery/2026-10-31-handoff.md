## 使用与换机

获取当前分支，按 [安装手册](../USAGE.md) 安装后运行 `ergora serve`，打开本机 `http://127.0.0.1:8977`。远程机器通过 SSH 转发访问。注册业务项目自己的 Git 仓库，在工具页按角色选择；正式开发使用参考运行时与显式桥接，训练使用可信 runner 和证据批准。具体命令见 [Agent 手册](../AGENT_BACKENDS.md) 与 [训练手册](../TRAINING.md)。

应用、可选工具、运行状态使用分离的持久目录。备份用户状态、工具配置及业务 Git 仓库；换机重新配置真实项目路径、凭据和设备。源码仓库不带登录状态或运行数据。继续开发前读 AGENTS.md、PLAN、活动记录并核对 Git 分支与状态。
