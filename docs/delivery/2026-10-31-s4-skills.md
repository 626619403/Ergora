# S4：skill 候选、可信评价与采用回退

用户授权优先补足可持续优化 skill 的 RSI 能力。延续 Agent Skills `SKILL.md` 目录，不新造 skill DSL。候选完整目录以 SHA256 定址，保留父版本、来源、假设；评价输入和可信命令固定，分别保存 train / validation / holdout 的结果、失败与报告成本；比较后人工明确采用，并能回退。

实现边界：`skills.py` 管理标准资源及版本采用；`evaluation.py` 管理固定评价合同、外部 evaluator 调用与证据；可选 GEPA 引擎负责搜索，只能通过明确消费者生成候选，不直接改活动版本或评分。CLI 与后续 Web 复用。数据放持久 state 目录，未配置真实可信 evaluator 时拒绝将候选当成已验证提升。

Agent Skills 的 YAML frontmatter 采用 PyYAML safe_load，避免自造不完整 YAML 解析器；新增小型基础依赖 `PyYAML>=6.0.2,<7`。GEPA 使用可选依赖 `gepa==0.1.4`，不安装整个其他 harness。依赖和接口需在独立环境实际验证。

当前状态：已实现，最终验证完成，独立审查待进行。不运行未经用户单独选择的收费模型优化，不更改正式六阶段或训练门禁。

变更：`skills.py`、`evaluation.py`、`optimization.py`、CLI 新命令、tool optimizer 绑定、`tools.run_agent` 的显式 skill / memory 消费、`processes.run` 的输入归档、`tests/test_skills_evaluation.py`，以及 pyproject、README、INTEGRATIONS 和 PLAN。新代码通过公开基础包调用参考合同，不重写六阶段。

验证环境：非 editable wheel 安装的 Python 3.11.15、PyYAML 6.0.3、真实 GEPA 0.1.4。`python -m build --wheel --outdir dist`、重装 wheel、`.venv-dev/bin/python -m pytest -q tests`：**20 passed**，其中 S4 五项集成测试。测试涵盖完整目录身份、来源目录变更不改快照、真实 evaluator 进程、部分证据/holdout 退化拒绝、评分文件变更拒绝、采用修订冲突、持久回退/导出、symlink 和错误响应拒绝、成本超限停后续调用。采用后与回退后的 agent argv 进程实际消费相应 skill 版本和来源记忆。

真实 GEPA 回归使用确定性提案进程，搜索确实选择不同候选，限制 metric calls / proposals，接口不发送 holdout，活动头保持 baseline。另验证错误提案不能被 SDK 内部捕获后误报成功。初次集成发现必须显式声明 `propose_new_texts=None`（协议默认字段不自动存在于 duck type）；已修复并实际重跑。

未验证：真实模型评分、模型生成提案质量、泛化收益、恶意同用户进程隔离、强计费限额；报告成本是回执，不是账单硬限制。评分文件和声明依赖有身份检查，但全部环境和外部数据依赖须由维护者固定。具体使用约定在 [INTEGRATIONS](../INTEGRATIONS.md)。

## 独立审查修正

首次独立审查确认五项问题：argv 中实际评分文件可漏声明、评价全部失败仍被 GEPA 汇总为成功、累计成本没有传递到批次内、可执行位未参与目录身份、case ID `work` 与内部目录冲突。已对 argv 中存在的文件自动补充 SHA（不改未声明 argv 的字符串语义）；失败评价终结搜索；每批使用剩余成本上限并在首个越限后停止；内容清单加入文件 executable_bits；输出移到 `cases/<id>`。

回归补充实际评分脚本漏声明后变更拒绝、chmod 身份与存储篡改拒绝、全 evaluator 错误搜索失败、累计 .45 成本上限在第一项越限后停批，以及合法 `work` ID 的完整评价成功。最终非 editable wheel 安装后 S4 为 **8 passed**；等待审查者复验。

第一次复核进一步复现评分 argv symlink 换链，以及评分身份检查异常被误当成候选格式错误。已固定原路径→目标路径绑定并在每次使用前后检查；将候选导入拒绝与可信 evaluator 调用错误分开处理，后者终结搜索；引擎返回前再次检查评分身份。新增两项实际回归，最终 wheel 非 editable 安装后 S4 **10 passed**，等待第二次复核。

[第二次独立复核通过](2026-10-31-s4-review.md)，五项发现及同根遗漏全部关闭；审查者重跑 10 项，并另外实测已 eligible 后换链导致 run/compare/adopt 全部拒绝、真实提案器改 scorer 后跨进程读取 finished/failed，活动头不变。S4 完成。
