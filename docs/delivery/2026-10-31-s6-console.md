# S6：本地图形控制台与受约束工作单元编辑

用户希望在不同层选择工具、调整 agent 关系并易于操作。前序切片已提供真实服务层；本切片使用 FastAPI + 随包静态 JS/CSS，图展示复用 Cytoscape.js。无需运行时前端 CDN、Node 构建或外部工单服务。新增可选 web 依赖 FastAPI 0.162.0 / Uvicorn 0.54.0。

页面包括项目选择/注册、工具层绑定、实际运行与上下文、记忆/来源/修订、skill 候选 diff 与评价采用、资料候选，以及固定六阶段下的 work-unit DAG 草稿。图只编辑协议允许的依赖和路径，正式校验复用冻结参考合同；不任意拖改六阶段，也不根据页面自行产生正式验收状态。

CLI 与 Web 共用前序业务函数，持久草稿独立于正式冻结任务。服务只绑定 loopback，写入要求同源与自定义请求头，Host 约束和前端纯文本渲染保护本地操作边界；不声称团队身份或公网部署。浏览器将使用 Playwright 技能实际走通操作与错误路径。

页面交互已实现，三个模板均有实际入口：前两个提供 work-unit DAG / JSON 草稿编辑，训练优化提供完整 workload / experiment 文件预览和下载，不伪装为通用 DAG。页面不执行来源 HTML；模型输出和所有用户文本通过 DOM 文本节点显示。

重建并非 editable 安装 wheel 后，`.venv-dev/bin/python -m pytest -q tests/test_web.py`：**5 passed**。覆盖同源写入/Host/跨站拒绝、wheel 随包静态资源、CLI/Web 共用持久状态、绑定与记忆修订冲突/恢复、实际自定义进程调用、三个模板、正式 DAG 环及路径冲突拒绝、skill 完整双方评价/采用/陈旧修订拒绝。当前 FastAPI 的 TestClient 对 httpx 有上游弃用提示，测试无失败。浏览器验收与独立审查待进行。
