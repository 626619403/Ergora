## 首次发现

### 1. [Medium, CONFIRMED] 用户中断及部分启动错误不会持久化终态

- 位置：`src/ergora/tools.py:80`、`src/ergora/tools.py:82`、`src/ergora/processes.py:24`。
- 场景：运行一个睡眠命令后向 CLI 发送 SIGINT。进程层捕获 `KeyboardInterrupt` 并清理命令后重新抛出；工具层只捕获 `OSError`，因此不会执行 `finished` 和数据库更新。重开状态后该运行永久显示 `running`，已经终止的命令与真实在途命令无法区分。
- 实测：临时项目中结果为 `exit=-2, persisted_status=running, keyboard_interrupt=True`。另一个可达错误是绑定的 argv 含 `\u0000`：当前校验允许保存，`Popen` 抛出 `ValueError: embedded null byte`，也遗留 `running`。
- 最小修复：正常处理用户中断并保存 `cancelled` 等明确终态；在持久化运行之后，所有可处理的执行错误必须保存失败及结束时间。绑定应先拒绝 NUL，同时保留对 `Popen` 配置错误的失败记录。无需在此切片实现机器掉电或 SIGKILL 后的自动恢复系统。
- 置信度：100。

### 2. [Medium, CONFIRMED] 命令正常退出时，同进程组后代可在成功记录之后继续修改项目

- 位置：`src/ergora/processes.py:19`、`src/ergora/processes.py:28`。
- 场景：argv 命令 fork 子进程，父进程立即正常退出，子进程稍后写入项目。清理仅位于超时和异常分支，正常分支直接记录成功。该后代属于调用创建的原进程组，并未通过 setsid 主动逃离边界。
- 实测：临时命令返回 `status=succeeded` 时文件尚不存在，0.8 秒后项目中的文件出现。运行已经结束，超时机制却无法再约束该写入。这削弱本切片“有界工具调用”的含义，也不适合直接复用于后续可信 evaluator。
- 最小修复：把对所创建进程组的收尾放入覆盖正常、失败和中断的统一退出路径；容忍已不存在的进程组。增加正常退出但遗留同组后代的回归。共享用户边界下主动脱离进程组的子进程仍应明确属于限制，不要求本切片增加强隔离。
- 置信度：100。

### 3. [Medium, CONFIRMED] Claude 审查者的内置工具白名单不排除默认 MCP 工具

- 位置：`src/ergora/tools.py:68`、`src/ergora/tools.py:70`。
- 场景：用户或项目配置了一个已授权的 MCP 写入工具。`--tools Read,Grep,Glob` 只筛选 Claude 的内置工具，未禁止默认 MCP 配置加载，因此“Claude 审查只暴露读取工具”的声明不成立。
- 证据：安装工具的真实 `claude --help` 将 `--tools` 明确定义为 “available tools from the built-in set”；另提供 `--strict-mcp-config` 用于忽略默认 MCP 配置。被审查 argv 未使用后者。本发现是参数合同的静态核对，未运行模型或外部 MCP 写入。
- 最小修复：审查者显式使用严格 MCP 配置及空服务器集合；后续如开放 MCP，按明确的只读服务白名单配置。为生成的审查者 argv 添加回归验证。此处只要求声明的工具集合符合实际，不声称共享用户执行具备强隔离。
- 置信度：95。

### 4. [Medium, CONFIRMED] doctor 与执行器对相对命令路径使用不同工作目录

- 位置：`src/ergora/tools.py:46`、`src/ergora/tools.py:47`，对照 `src/ergora/tools.py:81`。
- 场景：在已注册仓库中存在可执行文件 `./local-tool`，绑定 argv 为 `["./local-tool"]`，从其他目录运行 Ergora。执行器把 cwd 设为项目仓库，能够成功执行；doctor 的 `shutil.which` 却相对 CLI 目录检查，误报未安装。相反，CLI 目录中同名文件也可能造成误报可用。
- 实测：同一绑定得到 `relative_doctor.installed=False` 与 `relative_run=succeeded`。
- 最小修复：doctor 对含路径分隔符的相对 argv[0] 按项目仓库解析，执行检查仍使用同样的 cwd 语义；不要用进程全局 chdir 实现，以免未来 Web 并发请求互相影响。增加从非项目目录调用的回归。
- 置信度：100。
