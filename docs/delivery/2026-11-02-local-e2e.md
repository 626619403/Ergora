## 实测中发现的配置前置条件

- 旧部署中一个 setup.py 与冻结发行不同，选择式执行器按设计拒绝该源码身份。未覆盖旧部署；从已打包发行复制干净参考源码到用户持久安装目录，复用已有工具环境，再在隔离配置中启动桥接。后续所有正式任务使用这份精确参考源码。
- `agentflow task` 的 Temporal 客户端直接读取 shell 的 TEMPORAL_ADDRESS / TEMPORAL_NAMESPACE / TEMPORAL_LOCAL_DEV，而参考生成 env.sh 没导出它们。独立环境入口已明确设置 loopback 开发连接；该易用性问题记入后续 R6/F2，不修改冻结 reference。
- Supervisor shutdown 返回时子进程可能仍在退出；第一次过早重启被 socket 占用拒绝。确认旧 socket/服务已退出后正常启动，没有强杀或争取额外权限。
- 记忆 save 的 --id 表示纠正已有记录，不能自定新 ID。验收脚本首次误用后已按实际合同改为新建自动 ID；完整修订/恢复/删除与 Skill 评价/采用/导出/回退的 20 次实际 CLI 调用通过。Skill 评分来自声明的确定性契约 harness，不证明真实模型 Skill 收益。
