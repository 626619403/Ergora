# F8：可选 Harness 的兼容准入与会话

产品基线 `784da65da89bdd2fed4742e57e3f904c0f295216`，分支 `refactor/architecture-foundations`；前片[D3c](2026-11-12-issue-writeback-console.md)自己的CI及原评审精确终核已完成，不能借给本片。

## 目标与责任

按[总计划F8](2026-11-01-all-in-one.md)先评估 OpenHands SDK 的固定版本接入，再评估 DeepSeek Harness 可复用部分。工具是否能安装、能调用模型、能满足正式组合的资源读取与权限合同、能恢复原生会话，分别记录。Ergora 保持基础 Python >=3.11；可选 SDK 使用独立环境，不增加基础安装负担。优先采用已有原生接口，不整包引入另一个派工、数据库或页面。

沿用 `AgentBackend`／局部实现映射、`Invocation`、原 `agents.invoke` 和进程所有者。实际正式消费者是同一模板的可替换叶后端，已有运行不得热换。若原生 SDK 没有完整限制工具／继承资料读取／结构化结果保证，明确标为不支持，不能仅填配置就宣称准入。调用状态／模型自报usage／原生会话状态与原任务恢复、可信产物、精确候选批准各有所有者；不建立第二账本，不把未知结果自动重跑。

本轮先做 H0，再按证据收窄 H1–H3；不承诺所有 Harness 同时兼容或所有 OS 同时通过。稳定Trigger仍依赖真实来源consumer另片，未关闭F7全部功能。没有真实账号业务写授权时只用本地项目与loopback服务。
