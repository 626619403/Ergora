# AC：完整评审、专长化Agent库与可嵌套工作流

日期：2026-11-08。当前项：AC0b嵌套工作流设计的新独立审查与交付；完整AC1已终结。研究固定源码`b1dbe48a1b14e8e2ec59d4f44e30b2ea367fa1fe`，AC0交付`0f8e2a98dbfa42ea96657ef80fbf2bc356f57abe`，分支`refactor/architecture-foundations`。恢复上下文先读[总计划](../PLAN.md)、本表、共享报告和Git实际状态，不按历史快照推断新功能完成。

## 目标和边界

让每个模板组合多个按职能及专长分工的Agent；每份独立定义描述后端、初始提示、Skill/MCP、权限与资料。执行/审查优先不同后端，各成员预算可不同，明确同后端回退原因。实现专业互补与审查覆盖，同时保留原六阶段、可信验证、精确候选、用户配置和Linux/Windows已支持范围。

用户追加：模板还应可复用地嵌套成静态有界工作流，支持串行/并行与显式汇合；各模板声明资源/权限，子实例完整装载当前路径全部祖先Skill指令和上下文，资源只增不减、权限不超过父级。父/子权限可在同一新修订中一起提高，但整条祖先链及项目授权上限必须成立，在途任务不改。此项依[ADR0005](../architecture/decisions/0005-composable-workflows.md)实施；当前工作单元DAG不等于已实现该功能。

研究、设计、代码实现、实际验证、独立审查、提交推送分别记账。本轮不直接改冻结283文件、不启动第二套调度器，也不把纸面配置显示成可用。参考资料见[研究](../research/2026-11-08-agent-composition.md)和[ADR0004](../architecture/decisions/0004-agent-composition.md)；原始独立发现及双方处置只在[共享报告](../delivery/2026-11-08-agent-composition-review.md)保留。

## 低代码能做到哪里

新专长定义：写版本化Agent包并选已有后端/资源；新模板：引用Agent/子工作流，组合职能、成员、具名产物和串并行关系。模板可逐层追加资源并收窄权限，调整父子权限时预览完整链和有效差异，再作为一个新修订保存；所有祖先声明的Skill指令和上下文必须在实际叶子前完整装载。以上由同一schema驱动CLI和页面，目前仍待实现。

新增后端、权限执行能力、可信验收或跨服务副作用需要adapter和合同实现，不属于纯配置。优先复用现有SDK/MCP客户端、JSON Schema、Agent Skills、ReMe/GEPA/MLflow/Forge；组合准入、候选绑定、互补覆盖及审查聚合由Ergora自己实现。没有实际差异时不增加继承层，没有真实消费者时不增加通用注册框架。
