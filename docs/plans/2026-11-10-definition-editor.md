## 所有者与范围

原 `definition_bundles` 负责标准正文转换，复用现有 PyYAML 与重复键 JSON 读取；YAML 只是 JSON 数据模型的编辑表示，库内仍为原 JSON。只接受字典根、字符串键、JSON 可表示值，拒绝重复键、别名/循环及其他 tag；解析最多64层/100000值（含映射键），超限拒绝；沿原HTTP的4MB请求限制，不截断。两种表示转换不创建版本、不读取项目或执行脚本。CLI `revise --format` 与 Web 转换入口共用所有者，发布仍只调用 C3a。

原 `definitions.js` 拥有库级请求、当前精确版本和编辑会话。会话固定控制目录/kind/原id/version/digest，保留已应用标准正文、表单缓冲、JSON/YAML原文和独立请求序号；本地缓存不当作持久版本。字段及JSON/YAML必须明确应用/放弃，未应用文本阻塞检查/发布旧正文。控制目录切换隔离库与请求；回到原目录恢复原文本，错误/迟到响应不得降级较新编辑。

Agent 表单支持版本/描述/职能/专长/后端请求。Workflow 表单支持实例、角色/审查职责、精确引用、依赖和端口；复杂字段仍可显式编辑标准JSON。后端选项使用现有目录元数据，不能把选择/检查当安装认证。共享字段渲染或历史逻辑只有出现两个实际消费者时才按共同接口提取，保持各自语义所有者，不引入新UI框架、浏览器YAML依赖或通用状态机。
