# 页面操作

简体中文 · [English](../../operations/console.md) · [文档目录](../../README.zh-CN.md)

1. **项目总览**展示真实记忆、Skill、资料提案和工具调用。可单次启动所选角色，并附带活动 Skill、项目记忆检索及可选模板产物要求。记录中可预览标准 / 诊断输出，每路最多 64 KiB；完整文件保留在持久运行归档。固定六阶段图是协议说明，不是伪造的任务状态。
2. **长期记忆**保存正文、来源 URI、来源版本和可选到期时间；可选UTF-8正文文件保留候选原文。更正预填原期限，清空明确移除；未编辑正文保持原换行。默认仅显示有效快照；“读取全部状态”展示已到期和已删除目录及服务端判定时刻。空查询重新读取有效列表。历史恢复单选原修订并追加恢复，沿用其原期限，删除不可恢复。保存／恢复／删除／投影同步仅在发起表单显示完整回执，随后明确刷新读取原状态；回复异常先核原记录。详见[候选保存](../improvement/retrospectives.md#生成来源绑定的记忆复盘候选)和[有效期说明](../improvement/memory.md#记忆有效期与检索)。
3. **Skill 演进**导入完整标准目录，首个版本建立初始基线。后续导入成为候选。先比较文件 / 文本差异，注册可信评价集，再运行双方评价和比较。达到门禁后填写采用理由；曾经活动的版本可填写理由回退。GEPA 只搜索候选，不自动采用。
4. **资料观察**填写 URL、总字节及时间预算。内容变化产生待核对提案；显示的正文仅是文本。审阅不自动写入记忆或修改 Skill。执行时可以刷新列表并请求取消，随后确认实际终态。异常退出的未决传输可能保守耗尽预算，需要明确创建新的观察任务。
5. **工作流设计**提供治理和大型开发的工作单元 DAG，编辑依赖、路径和说明，或载入完整 JSON。服务端调用原合同编译器拒绝环、冲突和非法范围。保存是持久草稿；下载 `input.json` 后继续走参考任务冻结和执行。训练模板提供 workload / experiment 等文件预览和下载，完整目录可从 CLI 复制。

Skill 页面可接收[复盘候选导出的完整目录](../improvement/retrospectives.md#生成来源绑定的skill复盘候选)。在“导入目录”填写控制台机器上该目录路径，核对完整返回；关闭窗口并用右上角“刷新”读取登记版本。选择基线、候选和维护者预先注册的可信 suite，分别明确执行评价；两按钮共享本窗口按控制目录与项目隔离的在途锁，切换标签或页面内刷新不解除，完整原记录会显示提交的 digest／suite 和各 case 结果。刷新后选择这两次精确 run ID，再“比较评价证据”。更改版本、suite 或 run 会撤下旧比较与采用表单，须重新比较。当前版本／suite 选择只是下一次评价输入；采用消费的是所选两条原评价记录及展示的 head revision，应审阅完整比较中的真实身份。

eligible 只表示原评价门禁通过。审阅完整证据、head revision 并填写理由后，才可“采用候选”；服务端重新核 suite、来源和并发 head。取得原结果后明确刷新，核对活动修订和版本列表。要回退，在曾活动版本旁选择“回退到此版本”，核对 digest／revision 并填写理由提交，再刷新读回。导入、评价完成、门禁通过、采用与回退分别保留原语义。

导入、suite 注册、采用、回退和 GEPA 提交后，当前表单转为完整请求／结果回执，不自动再提交或关闭窗口。评价／写入请求异常时先刷新核对原评价、版本与历史；评价回复不确定会继续锁住本窗口该项目的评价，核对后须明确点击“已核原记录，允许新的评价”。浏览器重载会丢弃临时界面锁，原请求仍可能执行，应先查原记录；回复丢失可能发生在原操作已执行之后。离开原页面或关闭／替换窗口后，迟到回复不弹新窗口、不通知或刷新后来页面；原操作仍可能完成，应回原项目读取记录。页面不保存跨刷新回执，请使用持久原记录与 CLI 核对。

## 编辑工作单元草稿

载入治理或大型开发模板后，先在表单修改单元ID、依赖、可写路径和任务说明，再点“更新单元草稿”；也可编辑完整JSON后点“校验并载入 JSON”。表单和JSON的未应用原文分别保留，不能直接覆盖另一处未应用文本。有未应用文本时，保存、下载、增删和撤销暂不可用；可切换单元继续编辑，或明确放弃相应文本。JSON和最终保存由原合同编译器校验，图形操作不能授予额外权限。

改名会同步更新依赖引用；新增、删除、表单应用和JSON应用可撤销重做。历史在本页保留最多50个快照、总计4MiB，超限时移除最旧快照；单份输入超过此预算时只保留当前输入。重新打开会保留当前缓冲并重建历史。拖动位置、缩放和视口单独保存，不进入任务JSON；“重新排布”只重设显示。

草稿ID改变后按新草稿保存。要修改已有草稿，请先从“已保存草稿”列表打开；页面只使用已载入或本会话保存回执中的目标修订，不自动采用刷新列表里的新修订。冲突时保留当前编辑，先复制或下载需要保留的内容，再明确重新载入。保存过程中继续输入会保留较新文本，迟到回复只登记原提交快照的保存事实。

浏览器缓冲按控制目录和项目分开，切页、切项目及刷新可继续编辑；关闭浏览器后的保留取决于浏览器会话恢复设置，长期保存须明确“保存草稿”。浏览器存储配额不足时显示警告，请保留该页并复制未完成文本；无效JSON也须先复制原文。损坏缓冲提供“下载原始缓冲”和“明确清除浏览器缓冲”，清除前请先保留原件。载入模板或已保存草稿会提示确认替换未保存修改。编辑、保存和下载均不自动启动正式任务。

详细 evaluator / proposer JSON 协议、来源快照、ReMe 与 Temporal 配置见 [工具接入手册](../../improvement/workflow.md)。
