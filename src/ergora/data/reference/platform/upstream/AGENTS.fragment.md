# 训练效率实验约定（合并到现有AGENTS）
- 先读workload-contract.md、baseline.json和负结果库；仓库已有优化不重复算新贡献。
- E：固定训练语义的工程变更；N：数值近似；A：算法/输入/结构/更新配方变化。结果分榜。
- 一个agent一个worktree。共享文件有唯一owner，Git元数据操作交给有权限执行端。
- baseline与验收工具受保护；禁止删检查、调阈值、缩工作量、缓存测试答案来通过。
- 调度器负责GPU租约，Temporal负责实验生命周期，agent负责候选；同一操作只有一个重试owner。
- 每次比较恢复约定初态，记录样本、增强、RNG、实际更新次数和最终配置。
- 无profiler完整运行才进入性能比较；NCU结果用于解释，不能代替整训时间。
- 数据等待、编码、目标、反向、更新、必要通信、长期保存/恢复成本均有明确统计范围。
- 局部快不等于组合快；每次基线更新后重新profile；失败结果保存触发条件。
- 日志和trace放artifact store；稳定链接、checksum和摘要入issue/PR；不提交密钥或庞大日志。
- 维护fallback、参数版本、缓存生命周期、运行时支持矩阵与删除计划。
