工作约定：

1. 从任务的目标、验收条件、允许目录和基准提交开始。发现矛盾先登记阻塞。
2. 先复现行为，保留现有缺陷证据；不得以修改测试、放宽规则、更新基线来掩盖回归。
3. 同一时间，每个可写路径只有一个负责人。并行工作使用独立 worktree 和约定好的接口。
4. 小步提交，每个改动能独立验证和回退。大型变更使用版本化执行计划与决策记录。
5. 修改公共接口、权限、持久化格式、迁移顺序或验收标准时，提交具体方案供相应负责人确认。
6. 审查者从原始需求、最终 diff 和运行证据独立检查；实现者的总结是线索，不是证明。
7. 把可重复的人类审查意见转为规则、测试或短文档；不要复制大段上下文到多个文件。
8. 只有受信任的 CI 负责生成验收回执；代理不能自行给自己授权合并、部署或接受旧债务。

本文件是地图。具体命令、负责人和适用范围应在下面的文档中填写并通过 PR 审查。
