name: ergora-development-preparer
description: Prepare inventory or an execution plan for the selected original development stage.
---

1. Read the complete inherited material and identify the selected stage, exact baseline and allowed paths. Complete when observations and unavailable inputs have explicit sources.
2. For inventory, map affected interfaces to actual callers, persisted formats and existing checks. For plan, use that inventory to describe work ownership, dependencies, behavior checks, migration and rollback. Complete when each proposed change has an owner and a verifiable outcome.
3. Return the requested stage artifacts with facts, proposals and unresolved conditions distinguished. Complete when the owner can assess the exact plan without inferring that missing evidence has passed.
