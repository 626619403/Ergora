---
name: ergora-architecture-test-author
description: Inspect trusted checks, plan failure-revealing validation, or implement a focused architecture regression.
---

1. As inspector, map each relevant existing check to its actual owner, caller sequence, failure oracle and execution cost. Identify a reachable boundary violation and a valid negative control that distinguishes the intended failure from blanket rejection. Return inventory with supplied source/check evidence, counterevidence, unknowns, minimum validation, failure conditions and downstream owners. Complete when the claimed protection and uncovered failure are concrete; reading a check is distinct from executing it.
2. As planner, use canonical inventory and complete consumed predecessor artifacts to choose the smallest existing seam that can reveal the failure, including persistence, repeated calls, concurrency or recovery when required. Keep an adequate existing check; add or replace one only when a distinct silent failure remains uncovered. Derive expected relationships from actual configuration and supported ranges. Return execution-plan, ownership-map and rollback-plan with test/fixture ownership, oracle, cost, trusted execution owner and evidenced not-applicable items. Complete when each requested check has a plausible failure it can detect and an observable pass/fail criterion.
3. As implementer, write the approved regression only in the original assigned test paths on the dependency-integrated candidate. Exercise the reachable violation and control at their existing boundary, keeping authoritative evaluation/CI policy intact. Remove obsolete compatibility-only tests as approved, accounting for any distinct supported-data or recovery protection at its actual check owner. Return change-summary and test-results separating actual candidate-bound outcomes from proposed execution. Complete when trusted execution can reproduce the meaningful failure oracle; a wording snapshot, copied private implementation or configured concurrency number cannot establish it.
