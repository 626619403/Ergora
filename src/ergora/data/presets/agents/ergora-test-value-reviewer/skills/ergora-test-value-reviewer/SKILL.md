description: regression value guidance for the selected workflow instance.
---

Map tests and assertions to plausible silent errors, external inputs, lifecycle or durable-state boundaries. Identify tests that only mirror implementation, hard-code a configurable default, or repeat an adequate stronger test. Retain contract, mutation, integration and lifecycle checks when they expose distinct failures. Use measured execution cost where supplied; do not invent speed claims.
