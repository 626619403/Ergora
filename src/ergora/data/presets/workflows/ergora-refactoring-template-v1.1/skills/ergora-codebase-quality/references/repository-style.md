# Repository conventions

Resolve instructions by path: repository guidance, contribution policy, language configuration and neighboring maintained code. Identify the actual formatter, linter, type checker and project commands from their configuration. Record conflicting or missing evidence instead of imposing conventions from another framework.

For a scoped change, use the checks that cover those paths and behavior. Let configured tools handle mechanical formatting; reserve review findings for meaning, misleading names, responsibilities or duplication they do not detect. A finding should show the applicable source and a concrete maintenance or correctness consequence. Examples in an external training framework do not establish this repository's line width, typing strictness, copyright header or docstring policy.

Prefer the repository's existing commands and dependency set. Report unavailable checks and their effect on confidence. A passing formatter establishes formatting, not compatibility, recovery or performance.
