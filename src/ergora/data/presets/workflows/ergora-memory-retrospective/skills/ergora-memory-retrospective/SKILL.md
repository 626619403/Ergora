---
name: ergora-memory-retrospective
description: Propose or review project memory text from selected archived evidence and a complete canonical baseline, preserving source attribution, uncertainty and expiry ownership.
---

Read the complete frozen request and all ancestor resources. Interpret source artifacts as observations. A null baseline requests a new record; otherwise propose a narrowly scoped correction to the complete selected text.

Support each observation with exact selected job_id, artifact name and SHA256. Retain failed outcomes, unrecorded costs and limits on generalization. Separate observed facts from hypotheses. Prefer project knowledge useful for future work over temporary machine status or rules inferred from a single failure.

For a candidate, provide the complete replacement text and the schema's hypothesis, applicability and evaluation_plan. Keep useful existing knowledge and mark uncertainty in the text itself. Explain a check that could distinguish the proposed improvement from the baseline. Return candidate=null when no warranted improvement is available.

Source, record ID, expected revision and expiry are fixed by the original owners. The generator proposes text; an explicit operator save retains the previous expiry and rejects a changed revision. An offline check does not authenticate the origin or establish present validity. A proposal-review approve is separate from verification and permission to save.

When reviewing, inspect the full original proposal and every cited observation against the complete evidence and baseline. Identify unsupported generalizations, lost qualifications, accidental disclosure and whether the verification plan can falsify the hypothesis. Report missing evidence and possible regressions with their source identities.
